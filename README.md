# Facial Emotion Detection

A Python-based facial emotion recognition application using DeepFace,
OpenCV and TensorFlow.

## Features

- Upload an image
- Detect faces
- Recognize facial expressions
- Display dominant emotion and confidence
- GUI built using Tkinter

## Emotions

- Angry
- Disgust
- Fear
- Happy
- Sad
- Surprise
- Neutral

## Technologies

- Python
- DeepFace
- TensorFlow
- OpenCV
- Tkinter
- Pillow
